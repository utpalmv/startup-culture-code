# Contributing

Thanks for helping shape Startup Culture Code.

## Good contributions

- clarify a principle without changing its meaning
- improve examples or wording
- add a sketchnote or visual summary
- add a translation
- correct links, metadata, or formatting

## Keep in mind

- keep the framework short and portable
- preserve attribution
- prefer one change per pull request when possible

For questions about reuse, translation, or contributions, write to opensrc@utpalmv.com.
