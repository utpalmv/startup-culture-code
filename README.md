# Startup Culture Code

Forkable source for the Startup Culture Code framework.

## What lives here

- `framework.md` for the canonical framework text
- `principles/` for one markdown file per principle
- `origin/` for the origin story and provenance notes
- `assets/` for diagrams, SVGs, exports, and reusable visuals
- `sketchnotes/` for hand-drawn or visual summaries
- `translations/` for future language versions
- `CHANGELOG.md` for versioned updates

## Canonical coordinates

- Public site: https://startupculturecode.org/
- Original author: https://uv.bio/
- Origin archive: https://utpalmv.com/culture-code/
