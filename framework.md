# Startup Culture Code

Startup Culture Code is a seven-principle framework for treating startup culture
as a product, a system, and a set of choices that can be named, reviewed, and improved.

## Thesis

Culture is the product every startup builds for itself.

## Principles

1. Assume Nothing
2. Take Bottomline Ownership
3. Embrace Change
4. Push Our Limits
5. Pay Insane Attention to Detail
6. Listen to and Speak the Truth
7. Create World-Class Everything

## Usage

- Use the principles in hiring, roadmap debate, execution, conflict, and review.
- Keep source edits versioned and attributable.
- Keep visual summaries, sketchnotes, and translated versions alongside the text.
